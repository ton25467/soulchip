# 📋 Whiteboard: Deploy Team

**กระดานระดมความคิดเห็นและข้อเสนอแนะภายในทีมส่งมอบและติดตั้งระบบ**

---

## 📌 ไอเดียและข้อเสนอแนะปัจจุบัน (Active Suggestions)

### 1. การขยายขีดความสามารถการรับส่งข้อมูลของ Mock Server (Server Rate Limiting configuration)
* **ผู้เสนอ**: เบสท์ (มงคล - Server Engineer)
* **รายละเอียด**: 
  - เมื่อยิงสถิติเฟรมเรตหรือปัญหาเข้ามาที่ `/report` เสนอให้ใช้คิวแบบอะซิงโครนัส (Async Channel Queue) เพื่อรองรับการยิงข้อมูลพร้อมกันเมื่อมีผู้เล่นพร้อมกันจำนวนมาก
  - *เป้าหมาย*: ป้องกันไม่ให้ตัวเกมนิ่งค้างชั่วขณะ (Micro-stutter) ตอนยิง Log เข้าเซิร์ฟเวอร์
* **สถานะ**: ⏳ รอความคิดเห็นจากฝ่ายตรวจสอบคุณภาพ (Testing Team) ในการทำโหลดเทสย่อย

### 2. ตัวสร้างคอมไพล์ไบนารีระบบข้ามแพลตฟอร์มอัตโนมัติ (Automated Cross-compilation helper)
* **ผู้เสนอ**: อาร์ม (สุรเดช - Senior Compiler Engineer)
* **รายละเอียด**:
  - เสนอให้ปรับแต่งสคริปต์คอมไพเลอร์ให้รองรับการ Build ไฟล์เป้าหมายเป็น Windows (.exe), Linux (ELF), และ WebAssembly (Wasm) ควบคู่กันไปในการกด Deploy ครั้งเดียว
* **สถานะ**: ✅ อนุมัติแผนงานและเตรียมจัดหาเครื่องมือทดสอบในเฟสถัดไป

### 3. ระบบล้างไฟล์แคชติดตั้งเก่าโดยอัตโนมัติ (Automated Cache Purge)
* **ผู้เสนอ**: ดิว (วรวุฒิ - Release Coordinator)
* **รายละเอียด**:
  - เสนอให้เขียนคำสั่งล้างโฟลเดอร์ชั่วคราว (Temp caches) ก่อนบิวต์ไฟล์เวอร์ชันใหม่ เพื่อป้องกันขยะโค้ดค้างส่งผลต่อขนาดแพ็คเกจเกมหลัก
* **สถานะ**: 🛠️ ระหว่างทดลองใช้ในสคริปต์ Build ปัจจุบัน
