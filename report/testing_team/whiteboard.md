## 📌 ไอเดียและข้อเสนอแนะปัจจุบัน (Active Suggestions)

### 1. การเพิ่มการทดสอบคีย์บอร์ดติดขัด (Keyboard Jamming & Delay Adversarial Test)
* **ผู้เสนอ**: บาส (ชัยวัฒน์ - Senior Adversarial Tester)
* **รายละเอียด**: 
  - เสนอให้เขียนสคริปต์จำลองการกดปุ่มปีนบันไดพร้อมกับการกดย้ายหน้าสัมภาระแบบถี่ ๆ (50 ครั้งต่อวินาที) เพื่อตรวจสอบว่ามีเฟรมเรตหรือ TPS ตกฮวบลงหรือระบบเกลียวเกิดขัดแย้งหรือไม่
* **สถานะ**: ⏳ รออนุมัติพ่วงเข้ากับชุดทดสอบ Adversarial Test หลักในรอบหน้า

### 2. ขยายเกณฑ์ตรวจสอบการดรอปของข้ามชั้น (Multi-floor Drop Verification)
* **ผู้เสนอ**: โดม (อดิเรก - Senior Unit Tester)
* **รายละเอียด**:
  - เพื่อรองรับฟีเจอร์สลับคู่หู เสนอให้ทำ Unit Test สุ่มทิ้งของที่ชั้น 1 แล้วสลับตัวละครชั้น 4 เดินกลับลงมาเก็บว่าสิทธิ์ไอเทมและการอัปเดต HUD ทำงานร่วมกันได้ดีไม่มีขาดตอน
* **สถานะ**: ✅ อนุมัติการบรรจุเป้าหมายเขียนโค้ดชุดทดสอบเพิ่มเติม

### 3. การมอนิเตอร์หน่วยความจำสไปรต์แอนิเมชันขนาดยักษ์ (Large Sprites RAM Leak detection)
* **ผู้เสนอ**: ส้ม (สุดา - Diagnostics Auditor)
* **รายละเอียด**:
  - เนื่องจากทีมทำบอสส่งสไปรต์ตัวละครขนาด 128x128 พิกเซลเข้ามา เสนอให้มีการรันคำสั่งเช็ก Memory Footprint เป็นพิเศษระหว่างทำการทดสอบสู้กับบอสม่วง
* **สถานะ**: 🛠️ ออกแบบวิธีการบันทึกร่วมกับทีมโครงสร้างหลัก
