          SOULCHIP 3D SURVIVAL HORROR PUZZLE GAME - PROJECT PROGRESS SUMMARY

- ภาษาโปรแกรม: Go 1.26
- ไลบรารีการเรนเดอร์: Ebitengine v2 (ใช้เฉพาะ Standard Library ไม่ดึง 3D Engine อื่นภายนอก)

- สถาปัตยกรรมระดับด่าน: คฤหาสน์ 4 ชั้น (12x12 ตารางกริด) เสิร์ฟด่านผ่านเครือข่ายจำลอง

--------------------------------------------------------------------------------
1. ระบบที่เสร็จสิ้นสมบูรณ์แล้ว (Sprints 1 - 8)
--------------------------------------------------------------------------------

1.1 ระบบเรนเดอร์ 3D Perspective Software Engine
   - สมการ Project3D: ทำมุมเอียง Yaw 45 องศา, ก้มกล้อง Pitch 35 องศา และหารค่าเฉลียงด้วยความลึก Z (Perspective Division)
   - วัตถุที่อยู่ไกลจะบีบตัวเข้าหากลางภาพและมีขนาดเล็กลง วัตถุอยู่ใกล้จะมีขนาดใหญ่ขึ้น
   - สไปรต์ตัวละคร Gopher จะปรับสเกลขนาด (Perspective Scale) ตามระยะห่างจากตัวกล้องจริง
   - ระบบ 3D Painter's Z-depth Sorting: รวบรวมแผ่นพื้น, กำแพง 3D ลูกบาศก์ (8 ยอดมุม), ประตูล็อก, ไอเทม และผู้เล่นลงใน Render Queue และทำการจัดเรียง Z-Sorting ก่อนวาด เพื่อไม่ให้เกิดภาพบดบังกลืนกัน

1.2 ระบบกล้องเลื่อนตามอย่างลื่นไหล (Smooth Camera Follow)
   - กล้องจะเคลื่อนที่เฉียงสามมิติติดตามตัวละครผู้เล่น Gopher ให้อยู่กึ่งกลางจอภาพหลัก (320x320)
   - ใช้สมการเฉลี่ยความเร็วสะสมเฟรม (Lerp Interpolation) เพื่อการติดตามอย่างนุ่มนวล
   - แยกคำนวณการเดินกระโดด (Sin-wave Bobbing) ออกจากการควบคุมกล้อง เพื่อป้องกันหน้าจอเกมสั่นไหวถี่ในแนวดิ่งขณะตัวละครก้าวเดิน

1.3 ระบบขึ้นลงบันไดสองทิศทางแบบ RE0 (Staircase System)
   - เปลี่ยนการย้ายด่านแบบเดิมเป็นการกดปุ่มสัมผัสบันไดขึ้น (TileStairsUp) และบันไดลง (TileStairsDown)
   - เมื่อยืนทับบันได จะปรากฏแผง UI โปร่งแสงแจ้งเตือนลูกศรชี้ขึ้น/ลงตรงกึ่งกลางขอบบนหน้าจอ
   - ล็อกปุ่มกดทิศทางชั่วคราวและเล่นแอนิเมชันสไลด์ขึ้นลงขั้นบันไดแบบอัตโนมัติ (ขยับเฉียงสูง-ต่ำถี่ๆ)
   - รองรับการปีนย้อนกลับลงมาเคลียร์ปริศนาชั้นเก่าได้ตลอดเวลา ด่านใหม่จะ Snap กล้องทันทีที่เกิดเพื่อลดอาการตาลาย

1.4 ระบบทิ้งไอเทมระบุพิกัดแบบ RE0 (Item Drop System)
   - ปรับปรุงแถบ HUD 5 ช่องเก็บของด้านล่าง ให้แสดงกรอบสีทองไฮไลท์สล็อตเลือกใช้งาน
   - กดปุ่มตัวเลข 1-5 หรือ Tab บนคีย์บอร์ดเพื่อย้ายกรอบ และกด Q หรือ Backspace เพื่อทิ้งของ
   - ไอเทมจะตกลงไปเกิดใหม่บนแผนที่ตรงพิกัด Isometric 3D ที่ตัวละครยืนอยู่
   - ป้องกันการโยนทิ้งของทับซ้อนไอเทมชิ้นอื่น และห้ามทิ้งของทับพิกัดบันได
   - ผู้เล่นสามารถเดินเลี้ยวอ้อมกลับมาเหยียบซ้ำเพื่อเก็บไอเทมเข้ากระเป๋าเป้ใหม่ได้ตลอดเวลา

1.5 ระบบเซิร์ฟเวอร์จำลองข้อมูลด่านและกำแพงลวงตา (Mock API & Partition Scanner)
   - เปิดสปินอัพ Local HTTP Server บน localhost พอร์ตแบบไดนามิก (:0) เพื่อดึงข้อมูลแผนที่แบบ Asynchronous
   - อัลกอริทึม scanPartitionWalls: ทำหน้าที่ตรวจสแกนกำแพงกึ่งกลางแยกห้องต่างๆ ของสถาปัตยกรรมคฤหาสน์ 12x12
   - ระบบคำนวณเกิดกำแพงลวงตาแบบสุ่มไดนามิก (สเกลทวีคูณ n^n): ด่าน 1 สุ่ม 2 จุด, ด่าน 2 สุ่ม 4 จุด, ด่าน 3 สุ่ม 27 จุด

1.6 ระบบตรวจสอบและรายงานข้อผิดพลาดเข้าเซิร์ฟเวอร์ (Instant Backend Error Alert)
   - ปฏิบัติตามมาตรฐานคู่มือ autotesting.md อย่างเคร่งครัด
   - การรัน unit test ทุกรอบหากพบล้มเหลวแม้แต่จุดเดียว (code != 0) ตัวฟังก์ชัน TestMain จะสั่ง HTTP POST ยิงแจ้งเตือนเข้ารูเตอร์ backend /report เพื่อพิมพ์แจ้งเตือนตัวหนังสือสีแดง 🚨 ทันที

2. แผนการพัฒนาระบบกล่องฝากของจำกัดช่องฝากรายห้อง (Localized Capacity Item Box)
--------------------------------------------------------------------------------

2.1 วัตถุประสงค์
   - เลียนแบบขีดจำกัดคลังเก็บสัมภาระคลาสสิกของ Resident Evil 0 ที่ผู้เล่นไม่สามารถพกหรือรวมฝากของทุกชนิดไว้ในหีบเซฟที่เดียวได้ ช่วยเสริมมิติด้านโลจิสติกส์

2.2 รายละเอียดกลไก (Specifications)
   - กำหนดกระเบื้องประเภทหีบไม้/หีบเหล็ก 3 มิติ (TileItemBox - รหัส 10) ยืนประชิดกด Space/Enter เพื่อเริ่มเปิดเมนูฝากของ
   - ความจุของหีบแต่ละชั้นจะไม่เชื่อมถึงกัน (Localized Capacity Storage):
     * ชั้นที่ 1 (โถงใหญ่): จุได้ 6 สล็อต (หีบหลัก)
     * ชั้นที่ 2 (ห้องสมุด): จุได้ 4 สล็อต
     * ชั้นที่ 3 (บอลรูม): จุได้ 3 สล็อต
     * ชั้นที่ 4 (ห้องแล็บใต้ดิน): จุได้ 2 สล็อต (เซฟเหล็กจำกัดพื้นที่สุด)
   - อินเตอร์เฟซแลกเปลี่ยนแบ่งครึ่งจอ (Split HUD Interface):
     * ฝั่งซ้ายแสดงสัมภาระของ Gopher (5 สล็อต)
     * ฝั่งขวาแสดงสัมภาระในกล่องเซฟตามชั้นนั้นๆ
     * ใช้ปุ่ม A/D สลับคอลัมน์ และปุ่ม W/S ย้ายตำแหน่งช่องชี้เล็ง
     * กด Enter/Space โอนย้ายไอเทมข้ามฝั่ง และกด Q เพื่อปิดเมนูกลับมาเล่นเดินปกติ
